Abrir período do mês

cria relatório

Cria o relatório do mês corrente clonando a estrutura do relatório base selecionado e dispara Mensagem 1 (abertura) para cada autor com Notificações = Ativas. Idempotente sem force; com force reabre mesmo se já existir.

Notificar usuário

e-mail

Dispara manualmente uma das três mensagens do ciclo para um relatório existente. A decisão do coordenador é soberana para os tipos manuais, com uma exceção operacional: Abertura respeita idempotência por relatório (se já foi disparada para o relatório, o sistema bloqueia novo disparo e orienta usar outro tipo). Lembrete e Última chamada disparam a Mensagem 2 para entregas ainda pendentes, ignorando o calendário do ciclo (executa fora do dia configurado).

Retry · falhas recentes

retry

Retenta envios que falharam nos últimos 7 dias, até 3 tentativas por par (entrega, tipo). Cria nova linha em notificacao_envio a cada tentativa para audit trail.
